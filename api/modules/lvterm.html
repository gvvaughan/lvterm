Module lvterm

A virtual terminal, for testing programs that draw on one.

Feed a Terminal the bytes that a program writes, and ask what the screen shows, and where the cursor is:

local lvterm = require 'lvterm'
local term = lvterm.new(24, 80)
term:write '\27[2;3Hhello'
term:text(1, 2, 5)   --> 'hello'
term:cursor()        --> 1, 7

libvterm emulates the terminal, called directly through the FFI of LuaJIT where there is one (the ffi backend), and otherwise through a thin C binding (the core backend). The environment variable LVTERM_BACKEND, set to ffi or core, makes lvterm use that backend or fail, rather than fall back to another one, so that a test run is certain of which it exercises.

new ([rows=24[, cols=80[, options]]])
Make a new virtual terminal.

Parameters:

  • rows int height in lines (default 24)
  • cols int width in columns (default 80)
  • options table scrollback, the most lines to keep of those that scroll off the top, which is as many as there is memory for if it is not given, and none if it is 0 (optional)

Returns:

    lvterm.terminal.Terminal

Fields

backend
Which backend makes terminals here.
  • backend 'ffi' or 'core'
