Module lvterm.terminal

A virtual terminal, over the handle that a backend makes.

A backend makes a handle, which has write, resize, reset, cursor, cell and output methods, and nothing else, so that terminals made by any backend behave the same. The Terminal here checks positions, and reads text, once, for all of them.

terminal:changes ()
Take what has changed on the screen since the last call. A terminal that is made with changes = true keeps what a program changes on its screen, in order, until they are taken, so that a program that draws the screen again can leave what is the same as it was. Each change is a table with a kind, and positions that are from 0, like the others:

  • 'damage': the cells of the rectangle that begins at row and col, and is rows high and cols wide, have changed.
  • 'move': the cells that were at from_row and from_col are now where the rectangle that begins at row and col, and is rows high and cols wide, is, as when the screen scrolls. Each scroll is one move, and the lines that it made are damaged after it, so that the changes in order, done to a copy of the screen, reproduce the screen.
  • 'cursor': the cursor is at row and col, which it was at from_row and from_col when the changes were last taken, and visible is whether it is shown. It is the last, and only if the cursor is not where it was.

The most that are kept until they are taken is 1024 of damage and moves, after which they are one change of all of the screen. The size of the terminal being changed, or the terminal being reset, is a change of all of it.

Returns:

    table the changes, which are removed from the terminal

Usage:

    local term = lvterm.new(24, 80, {changes = true})
term:write 'hello\n'
for _, change in ipairs(term:changes()) do
   print(change.kind, change.row, change.col)
end

terminal:runs (row)
What one row of the screen shows, as runs of cells that are drawn alike. A program that draws a row, such as the screen of a terminal in an editor, does so a run at a time, which is a call for each run, and not for each cell.

Parameters:

  • row int line to read, from 0

Returns:

    {table,...} the runs, from the first column to the last, each with col (the first column, from 0), cols (how many columns, which add up to the width of the screen), text (the text of its cells, as cell gives them, so that the right half of a wide character has none), and the fields of cell that cells are alike in: bold, italic, blink, reverse, conceal, strike, underline, fg and bg. The tables are not to be changed, as the ffi backend gives the same ones again for a row whose cells have not changed since, so that a program can tell that a row is the same by comparing them.

terminal:selections ()
Take the sequences for the selection that the program wrote. A program that copies text to the clipboard of its terminal, or reads what it has (OSC 52), writes sequences that only a terminal that is made with selections = true keeps; others discard them. Each is a table with a kind, and the mask that is the letters of the sequence for the selections, which are c for the clipboard, p for the primary selection, q for the secondary, s for the selection, and 0 to 7 for the cut buffers:

  • 'set': the program set the selections to text.
  • 'query': a sequence that reads what the selections are, which send_selection replies to.

At most 64 are kept until they are taken, and the oldest are dropped after that.

Returns:

    table the selections, oldest first, which are removed from the terminal

Usage:

    local term = lvterm.new(24, 80, {selections = true})
term:write '\27]52;c;aGVsbG8=\27\\'
term:selections()  --> {{kind = 'set', mask = 'c', text = 'hello'}}

terminal:unrecognised ()
Take the sequences that the program wrote that libvterm does not recognise. A terminal that is made with unrecognised = true keeps the control characters, escape sequences and strings that libvterm does not handle, so that a caller can act on those that it handles, such as the one that reports the directory of a shell (OSC 7). Each is a table with a kind:

  • 'control': a control character, as byte.
  • 'csi': a control sequence, with its leader, which is '' or a character such as '?', its numbers in args, which are false for one that is left out, a list of booleans in more that are true for each that is followed by one that is a part of it, after a colon, its intermediate characters and its command letter.
  • 'osc': an operating system command, with its command number and its text.
  • 'dcs': a device control string, with its command and its text.
  • 'apc', 'pm' and 'sos': those strings, with their text.

At most 256 are kept until they are taken, and the oldest are dropped after that.

Returns:

    table the sequences, oldest first, which are removed from the terminal

Usage:

    local term = lvterm.new(24, 80, {unrecognised = true})
term:write '\27]7;file:///tmp\7'
term:unrecognised() --> {{kind = 'osc', command = 7, text = 'file:///tmp'}}
