Module lvterm.terminal

A virtual terminal, over the handle that a backend makes.

A backend makes a handle, which has write, resize, reset, cursor, cell and output methods, and nothing else, so that terminals made by any backend behave the same. The Terminal here checks positions, and reads text, once, for all of them.

Class Terminal

A virtual terminal. Rows and columns are numbered from 0, like the arguments of curses.

What one cell of the screen shows.

Parameters:

  • row int line to read, from 0
  • col int column to read, from 0

Returns:

    table fields text (the characters, a space when the cell is empty, and the empty string for the right half of a wide character), width (columns, 1 or 2), bold, italic, blink, reverse, conceal and strike (booleans), underline (0 for none, 1 single, 2 double, 3 curly), and fg and bg, each nil for the default, an index into the 256 color palette, or a table of red, green and blue

terminal:runs (row)
What one row of the screen shows, as runs of cells that are drawn alike. A program that draws a row, such as the screen of a terminal in an editor, does so a run at a time, which is a call for each run, and not for each cell.

Parameters:

  • row int line to read, from 0

Returns:

    {table,...} the runs, from the first column to the last, each with col (the first column, from 0), cols (how many columns, which add up to the width of the screen), text (the text of its cells, as cell gives them, so that the right half of a wide character has none), and the fields of cell that cells are alike in: bold, italic, blink, reverse, conceal, strike, underline, fg and bg. The tables are not to be changed, as the ffi backend gives the same ones again for a row whose cells have not changed since, so that a program can tell that a row is the same by comparing them.

terminal:set_mode (name, value)
Set a mode that libvterm has no call for, as the program would, by writing the sequence that it writes. Unlike set_termprop, which wraps a call of libvterm, this is only for a test that stands in for the program not to write the sequences.

Parameters:

  • name string bracketed_paste or application_cursor_keys, with a value of true or false, or mouse_encoding, with a value of x10, utf8, sgr or urxvt for how the reports of the mouse are written, which is x10 until it is set
  • value the value of the mode

Returns:

    Terminal the terminal
terminal:set_termprop (name, value)
Set a property of the terminal, as vterm_state_set_termprop does. A program sets properties with the sequences that it writes, and this sets them as the program would have, which saves a test that stands in for the program from writing them. Only the properties for what the program is told are supported so far.

Parameters:

  • name string mouse, with a value of none, click, drag or move, as mouse_mode gives, or focusreport, with a value of true or false
  • value the value of the property

Returns:

    Terminal the terminal
