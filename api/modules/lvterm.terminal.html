Module lvterm.terminal

A virtual terminal, over the handle that a backend makes.

A backend makes a handle, which has write, resize, reset, cursor, cell and output methods, and nothing else, so that terminals made by any backend behave the same. The Terminal here checks positions, and reads text, once, for all of them.

Terminal:cell (row, col)
What one cell of the screen shows.

Parameters:

  • row int line to read, from 0
  • col int column to read, from 0

Returns:

    table fields text (the characters, a space when the cell is empty, and the empty string for the right half of a wide character), width (columns, 1 or 2), bold, italic, blink, reverse, conceal and strike (booleans), underline (0 for none, 1 single, 2 double, 3 curly), and fg and bg, each nil for the default, an index into the 256 color palette, or a table of red, green and blue

Press a key, as the terminal would send it to the program. What is sent depends on the modes that the program has set, such as the cursor keys, and is taken with output.

Parameters:

  • name string enter, tab, backspace, escape, up, down, left, right, insert, delete, home, end, pageup, pagedown, or f1 to f12
  • mods table which modifiers are held, shift, alt and ctrl (optional)

Terminal:mouse_button (button, pressed[, mods])
Press or release a mouse button, as the terminal would tell the program. The button is at the place that mouse_move last gave, and the program is told at once of a press or release if it asked for them.

Parameters:

  • button string left, middle, right, wheelup, wheeldown, wheelleft or wheelright
  • pressed bool true for a press, and false for a release, which a wheel does not have
  • mods table which modifiers are held, shift, alt and ctrl (optional)

Returns:

    Terminal the terminal
Terminal:mouse_mode ()
What the program asked to be told about the mouse. It is turned on by the program with a sequence such as ESC [ ? 1000 h, and mouse_move and mouse_button send nothing until it is.

Returns:

    string none, click for presses and releases, drag for those and moves while a button is down, or move for those and all moves
Terminal:mouse_move (row, col[, mods])
Move the mouse, as the terminal would tell the program. What is sent depends on what the program asked for with mouse_mode, and how it asked for it to be written, and is taken with output.

Parameters:

  • row int line that the mouse is over, from 0
  • col int column that the mouse is over, from 0
  • mods table which modifiers are held, shift, alt and ctrl (optional)

Returns:

    Terminal the terminal
Terminal:output ()
Take what the terminal has to send back to the program. A terminal answers some of the sequences that it is given, such as a request for the position of the cursor, and key, char, paste, mouse_move and mouse_button events that the program is sent.

Returns:

    string the bytes, which the terminal forgets

Terminal:text (row[, col=0[, n]])
Some of the text on the screen, from one row.

Parameters:

  • row int line to read, from 0
  • col int first column to read, from 0 (default 0)

Returns:

    string the text, a space for each empty cell, and so exactly as wide as the columns that it was asked for
Terminal:title ()
The title that the program set. It is set by the program with ESC ] 0 ; title BEL or ESC ] 2 ; title BEL, and is the last whole one, so one that is still being written is not it.

Returns:
